# Owned compatible DASH ladder

Generated by `python3 tool/generate_dash_variants_fixture.py` using local FFmpeg synthetic test patterns and sine audio; no external media. Two 4-second Periods, each containing separately encoded AVC Constrained Baseline level 3.0 at 320×180/350 kbit/s and 640×360/700 kbit/s, 24 fps, one-second GOPs, with shared AAC-LC 48 kHz mono audio. Video target bitrates are encoder/manifest bandwidth declarations, not measured transfer rates. Period 1 reverses representation ordering and changes IDs while retaining correct segment identities. `SHA256SUMS` records every MPD/media byte.

The Apple automatic-ladder public integration check covers current-session firstFrame, selected geometry/audio, natural progress past the Period boundary, seeking in both directions, completion, and requested initialization/media per Period. It records the observed selected geometry and requested video tracks. That automatic-ladder check does not force or assert weak-network ABR switching, fixed quality, a hard quality cap, HDR conversion, or minimum OS/device performance.

`manifest_missing_high.mpd` is a second manifest over the **same media bytes**. Period 0 is unchanged; Period 1 omits its 640×360 representation and retains 320×180 video plus the shared audio. The original `manifest.mpd` remains byte-for-byte unchanged. Android fixed-selection public tests use both manifests to distinguish identity rebinding from confirmed missing-quality fallback. `SHA256SUMS` includes the additional manifest for audit.
