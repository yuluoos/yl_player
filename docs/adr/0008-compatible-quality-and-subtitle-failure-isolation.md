# ADR 0008：兼容画质切换与字幕故障隔离

状态：2026-10-13 用户明确确认。

PD-02：跨 HDR/SDR 或不同 Dolby 路径的自动切换限于满足已选画质要求的兼容集合；不得丢失完整 FEL 信息。其他转换需要明确规则。

PD-03：字幕损坏或字体/图形资源失败单独报错并继续视频，保留稳定的字幕错误分类与会话关联。

该决定解除 P01/P02 对两项产品策略的等待，不代表相应实现或真实输出验收已经完成。需求权威入口为[需求基线](../superpowers/specs/2026-09-20-playback-expansion-requirements.md)。
