# 下一 Period 缺少固定档位时自动切回自动清晰度

2026-09-24，用户针对“固定 1080p，下一 Period 只有 720p”的场景选择“自动切回自动清晰度，允许降低到 720p”。此决定替代原待确认的“暂停并保留固定偏好”建议，对应需求基线 PD-01、REQ-04/05。

进入下一 Period 且无法匹配固定档位时，播放器进入自动清晰度模式，允许在其他已选约束内选择较低档位，并通过状态或事件让业务端观察到模式变化。固定档位仍存在时，仅因带宽不足不自动降档。跨 HDR/SDR 或其他杜比路径的转换仍受尚未确定的 PD-02 约束，不能把回到自动理解为解除硬解、画质或独立上限限制。

技术实现须定义稳定的档位身份和跨 Period 匹配规则；相同分辨率不自动证明编码、动态范围、角色和码率等条件满足固定选择。决定已获授权不表示接口、跨段恢复或三端验收已经完成。
