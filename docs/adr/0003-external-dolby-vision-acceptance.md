# 完整画质处理与外接原生 Dolby Vision 输出共同验收

用户于 2026-09-20 选择将外接电视的原生 Dolby Vision 输出纳入本次升级验收：除约定片源的完整 FEL 重建、适用动态显示元数据处理及独立参考画质对照外，还需在约定设备、连接方式和电视上验证 Dolby Vision 信号输出。仅播放器内画面正确的较小范围未被采用，电视显示 Dolby Vision 标识也不能替代画质验收。

此选择增加了显示输出链路和外接设备的验证范围，后续架构选择必须考虑该约束。具体 Profile、元数据版本、设备、操作系统、连接方式及参考输出尚未确定；本决定是交付目标，不是当前能力或所有三端设备均可实现的承诺。
