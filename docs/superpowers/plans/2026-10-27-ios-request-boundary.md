# iOS 请求边界与替换空档续查

基线 0e23b556，codex/abr-recovery。使用系统排查、测试驱动和集中验收；不发布，不降低原配置与策略门槛。

1. 增加仅 Debug 的代理边界计数快照和逐帧就绪/seek 门控观察，区分无新请求、上游悬挂、发送积压和解码等待。不得记录 URL、凭据或修改传输行为。
2. 在已授权 iPhone 上先执行原 down-and-recover-v1 auto 两轮；再执行既有 zero-latency 诊断 auto 两轮，对照上轮真实替换。每轮120秒，上限140/240秒。所有未触发与失败保留。
3. 只在时间线证明可消除的等待且安全条件保持时优化替换；否则保留空档和根因缺口。新帧与保留纹理分开，不把诊断 profile 当原配置验收。
4. 完成后统一受影响原生/工具测试、独立复审、证据哈希与发布台账更新。旧失败、缺设备授权项保持。
