# P07 CM4 原始输入与长形式对照

Base dde14f64。续接上一轮独立复审明确的本机缺口；不修改播放器/默认解析策略/研究 overlay，不操作另一聊天 iOS，不提交/合并/推送/发布。

1. 扩展测试专用 FFmpeg 对照器，输出 L9/L10 长形式的原始 AVRational 坐标；按固定 FFmpeg signed16/32767 表达核对 libdovi 保留的原始 u16 位模式，区分字节一致和物理色度合法性，不把码值当浮点显示参数。
2. 增加长形式生成视频，验证 B 帧重排、L10 静态继承/重置、逐包 L9 动态来源及短/长形式；含明确标记的有符号边界位模式，不作为画质目标。
3. 增加测试专用原始 RPU 构造器，跳过对象级写入校验但保留字段编码与正确 CRC；合法控制组必须逐字节等于原库写入器。通过真正 parser/状态器/解码 wrapper 验证缺 L254、压缩静态、重复/未知块等拒绝阶段，禁止把写入失败当解析证据。
4. 沿用集中验收：定向 RED/GREEN，全套 P07 与两种 Rust 构建、台账、一次独立复审，保留原始证据与仍缺的真实媒体/目标/设备/授权资格。
