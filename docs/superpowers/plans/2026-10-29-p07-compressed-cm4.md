# P07 压缩 CM4 动态块的显式研究支持

Base `0e919ee7`。延续 P07 来源链路前置验证；仅离线研究工具，不修改播放器、依赖锁或另一聊天 iOS。使用 consolidated-acceptance：定向 RED/GREEN，完成后集中全套和独立复审。不提交/合并/推送/发布。

设计：保持固定 libdovi 默认构建不变。新增 --compressed-cm4 显式构建选择，在经过归档哈希核验的临时提取源码上施加最小上下文校验补丁；完整 CM4 仍要求一个 L254，压缩 CM4 仅允许动态 L3/L8/L9/L11，拒绝静态块。补丁对两个输入/输出文件哈希逐项核验，记录构建变体与补丁身份。Python 状态器仅在已知同 ID/同配置且前序完整 CM4 静态 L254 存在时接受压缩 CM4；不新增未知版本推断或改变 schema。

实现与验证：先保留默认解析器拒绝真实原始压缩 CM4 RPU 的 RED；补丁构建运行 Rust 正反向契约；生成多 target/可变长度动态块的压缩序列，经 MP4 与 B 帧解码核对继承、过期、重置。用独立 FFmpeg 解码帧的 AVDOVIMetadata 扩展块作字段交叉验证，不依赖本项目状态算法。测试完整缺 L254、压缩静态、重复/未知块、历史被重置、坏 CRC、错误源码身份等拒绝路径。

默认上游限制仍保留；显式补丁支持只以实际测试子集表述，不宣称标准完整性。真实压缩视频、跨 ID/缺头/默认 DM、完整映射、独立画质目标/容差、设备与授权缺口继续开放。P08 无新同次因果证据，不猜生产补丁。
