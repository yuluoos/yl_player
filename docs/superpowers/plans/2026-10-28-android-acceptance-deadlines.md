# Android验收截止与所有权清理

基线 main eeaada6b。延续用户剩余项实施授权及集中验收约定。复用本聊天工作树，分支codex/android-acceptance-deadlines；不操作另一个聊天的iOS恢复。当前问题是上轮已观测的运行器阻塞，属于验收工具修复，不推导播放器/系统资源根因。

设计：保留shell入口及suite/参数契约，由Python标准库实现有界编排。所有显式adb均绑定YL_ANDROID_DEVICE_ID；preflight与Flutter共享600s执行截止，每次adb最多15s；退出后的进程组清理、必要前台恢复和失败日志共享30s清理截止。测试可通过显式环境参数缩短但不得扩大这些上界。SIGINT/TERM/HUP使用同一清理路径。只清理本次start_new_session启动的进程组，不kill全局adb、不重启设备、不操作其他工作树或共享Gradle daemon。失败保持原退出码；超时124；成功子进程但清理不完整必须失败。原始日志与JSON收据保留，收据区分执行结果、诊断/恢复、清理结果和实际设备。
