## 制品身份与采集

Swift 包改为动态库产品，解码器完整映像不再位于主程序中。外层重签对照：加入 schemaVersion 0 的无效测试资源并重签宿主后，严格签名检查通过，主程序哈希改变，Swift 解码器和编解码桥的完整文件哈希不变。无效测试资源不构成准入记录。运行中的实际身份指向独立库；不通过剔除签名字段或放宽哈希匹配解决问题。

采集宿主通过内部服务组合入口注入精确键及受控预算，SDK 公共注册仍使用生产签名档位。SDK 不读取环境变量来授予试验准入。观测使用可选资源账本峰值及实际解码帧数；生产默认不启用观测。协议、完整应用文件图和每次进程记录均冻结。Release 使用 -O 与 ENABLE_TESTABILITY，使独立宿主能够调用内部组合入口，资格只适用于这一精确解码器映像。

播放前预览层与定时层使用各自真实对象身份及 AVFoundation 计数。首帧补充记账要求公开 firstFrame 已完成、位置为零、software 模式、可见预览层恰好一帧且无掉帧/损坏；后续所有系统计数必须来自同一不同图层。不会仅凭最终少一帧推断首帧已经显示。

## 后续系统诊断与空闲基线

用户确认正式长测时保持桌面解锁、暂停并行重型构建。此前系统负载一度达到 294，CPU 无空闲；回落到约 64% 空闲后，在相同 SDK、夹具和门槛下启动新的独立基线。该轮 25.34 秒失败：显示层累计 481 帧、1 次丢帧、0 损坏，窗口始终可见，入队迟到计数为 0。原生调用最大 65.675458 毫秒未触顶。预算未冻结，未开始第二轮。失败保存在 `baseline-idle-failed`，不以短时空闲证明此前 127 毫秒故障的根因。

Instruments 的 `--launch` 曾按相同 bundle identifier 启动另一工作树的 Debug 副本。该轮无效；仅停止确认为本轮启动的子进程和 recorder，没有停止其他同名进程。后续改为直接执行冻结宿主，再按精确 PID 附加，运行时再次取得原 Swift/codec 身份。首轮附加开始较晚，只覆盖故障尾部；不能用它证明此前所有慢调用的原因。

为进一步区分音频时钟与显示故障，只在独立宿主增加现有会话统计读取；SDK 未改动。一次 16.41 秒诊断捕获音频读取 127.11 毫秒、1 次时钟过期，但该事件在约 2.5 秒，系统显示掉帧在 10–15 秒区间才出现。视频 worker 最大间隔约 12 毫秒，没有迟到入队，不能将两次事件直接认定为同一因果链。

再以播放前停点附加 System Trace 后恢复进程，获得 21.53 秒完整记录及带 uptime 的 signpost。播放约 15 秒时系统累计 360 帧、1 次掉帧；音频读取最大 17.95 毫秒、时间戳最大年龄 27.45 毫秒、过期次数 0，视频 worker 最大间隔 17.76 毫秒，迟到入队为 0。持续播放没有显著前向时间跳变。这轮排除了“所有丢帧都由时钟过期引起”的假设，但尚未确定原生显示队列内部根因。

普通像素缓冲与 IOSurface 的独立并排对照已完成：相同 24 fps、50 毫秒提交窗口、10 毫秒 timer 和固定 host timebase，不使用 Flutter、实时解码或音频。两路各计 4,320 帧、10 次丢帧、0 损坏；新增丢帧的采样时刻一致，窗口始终可见。普通缓冲最小提交提前量 14.26 毫秒；IOSurface 一次达到 -0.145 毫秒。该结果不支持通过更换缓冲分配解决当前显示故障，因此没有改动生产像素分配。对照进程 exit 0 只表示完整采集结束，不表示零掉帧或资格通过。

第一版并排对照缓存首帧的格式描述，重用第 96 帧时因格式不匹配退出（`kCMSampleBufferError_InvalidMediaFormat`），不构成有效比较。修正为与生产 `makeSample` 相同的逐样本格式描述后取得上述完整记录。两轮源码、计划与原始记录均保留。Apple 明确说明 `CVPixelBufferCreateWithPlanarBytes` 不会创建 IOSurface 支撑的缓冲；这只支持对照的分组依据，不证明丢帧原因。[Apple QA1781](https://developer.apple.com/library/archive/qa/qa1781/_index.html)

另外补齐签发器遗漏的既有时钟门禁：必须有连续真实 `QUAL_CLOCK`，过期次数为零、观测年龄及 worker 最大间隔不超过 100 毫秒。新增回归先证明过期、缺失时钟或 101 毫秒 worker 间隔都会被原签发器错误接受；修复后全部 5 项签发器测试通过。合成测试不构成设备资格。采集宿主通过已冻结 SDK 的现有统计输出这些字段，不修改采样算法或有效期。

Swift 动态产品使用 [SwiftPM 标准产品类型](https://docs.swift.org/latest/documentation/packagedescription/product/)；ENABLE_TESTABILITY 的具体编译和链接行为见 [Apple 构建设置](https://developer.apple.com/documentation/Xcode/build-settings-reference)。
