# iOS 按代理分别归因

基线 `8ebad124`，承接[触发式再次降档报告](2026-10-29-triggered-downshift.md)。本轮实现离线分组诊断，未修改生产播放代码、预算2或严格验收接口。目的为保留局部可证事实，不将缺失服务器关联视为通过。

新增 `summarize_scoped_rendition_retries` 和命令入口。全输入先经过一次既有结构与字节验证，再按代理分组；未关联请求保留原 requestID、取消来源及任务结果。本组关联不完整或存在不能归属的服务器媒体请求时，`highResets=null`，不能解释为没有重试。完整组只分析同代理请求的设备时钟；替换代理不算原代理重试。原严格函数的校验、返回结构和失败行为不变。

新增5项测试与既有3项重试测试合计8项通过，覆盖代理间同 requestID、未知请求、服务器遗失关联、坏数据/旧版本、时钟平移、严格拒绝和普通/gzip CLI。新接口缺失时反例失败，实现后通过。首次插入测试的位置错误导致一个 NameError，修正后才保存有效缺实现红日志，未将该脚本错误作为缺陷证明。一次独立只读审查无待修复问题，未重复测试。
