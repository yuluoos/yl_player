# Apple DASH active runtime video caps

Status: DONE WITH CONCERNS. The focused public acceptance passed on macOS 27 arm64 and iOS 27 iPhone 18 Pro Simulator; native acceptance was completed in the same stage (95/95 macOS, 97/97 iOS, then a focused metadata fix at 4/4 on each platform). No commit or push was made.

The existing `session.setVideoConstraints` Future now supports active accepted static clear AVC/AAC DASH. A successful change retains the session ID and measured position, preserves play/pause intent, publishes the filtered current-Period video catalog, and recompiles the accepted original MPD bytes without another root request. Completion means the new item and policy were committed; it does not promise a decoded frame or seamless output. An infeasible cap rejects with `decoder.quality_constraint_unsupported` without replacing the accepted session. An equal cap is a no-op. Inactive or restoring DASH changes still require a new Load. Fixed selection and selected bitrate remain outside this stage.
