# 播放器候选回归摘要

本轮验证的产品提交为 `1459a89054e6db225f656df8d74a2eba0b46e769`。测试工具调整了模拟服务的连接期限，并为 Matroska 用例留出验证 4,096 次请求上限所需的时间。Flutter 3.44.0 和 3.50.0 各通过 1,712 项播放器测试。

- Android JVM 测试在本地连接独立 RTMP 服务后通过 650/650，零跳过。
- macOS 通过 6/6 项 RTMP 集成测试，覆盖暂停恢复、连续断线重连和重试耗尽。
- iPhone 16（iOS 27.2）完成 44 项格式矩阵检查。40 项必测均通过，其中本地文件和受管 HTTP 各 20 项。另外 4 项记录了 MPEG-2 诊断和截断 MP4 的错误结果。物理音画同步和实际扬声器播放时钟仍待验证。
