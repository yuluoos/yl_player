# P07 DM 颜色头继承增量

基线 main `fa696c97332fd5f4c3134640f6a046caeac23ec0`；分支 `codex/dolby-dm-color-state`。本轮落实既有 P07 effective metadata 工作中的静态颜色头子项，修改仅在离线研究工具、测试和记录内。没有修改播放器、协议、依赖、iOS 恢复或生产准入。

## 已实现

新增 `--dm-color` schema 4，导出固定 libdovi 的原始 RPU header；在解码顺序内恢复压缩记录未携带的颜色字段，输出来源包、颜色整数值及哈希。压缩只接受已有同 ID、同配置的完整状态；新 epoch、缺 DM、未知位、ID 不一致、跨配置或压缩占位不为零时拒绝。原 schema 1–3 保留。详细边界见 [接口说明](../../../tool/dolby_reference/DM_COLOR_STATE.md)。

本轮从固定解析库源码确认压缩 DM 使用默认零字段；同时核对 FFmpeg n8.0.1 官方实现的颜色保留与 ID 拒绝语义。FFmpeg 仅作研究依据，不替换产品版本。状态解析不执行 CM/trim、NLQ、重采样或目标映射。
