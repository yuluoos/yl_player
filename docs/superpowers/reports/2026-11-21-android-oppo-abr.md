# OPPO Android 弱网播放与画质切换验收

2026-11-21，OPPO CPH2065（Android 12，API 31）上六轮公开 DASH 播放均到达素材末尾并完成释放。在 120 秒自动画质用例中，播放器经历了 640×360 → 320×180 → 640×360，服务端记录到相应的低档和高档视频分段请求。[逐轮结果](evidence/2026-11-21-android-oppo-abr/results.json)

| 场景 | 素材 | 观察结果 |
| --- | --- | --- |
| 自动画质，限速后恢复 | 40 秒 | 从 360p 降至 180p。最后一个视频分段在第 23.81 秒取完，恢复阶段无媒体传输，本轮未观察到升档。 |
| 自动画质，限速后恢复 | 120 秒 | 三个网络阶段都有媒体传输。限速后 6.19 秒首次请求低档视频分段，恢复后 1.67 秒首次请求高档视频分段。公开状态在恢复后 21.64–21.71 秒回到 360p。 |
| 限高 320×180、350 kbit/s | 40 秒、120 秒各一轮 | 两轮全部有效尺寸采样为 180p，无高档视频请求。40 秒素材在恢复前已取完；120 秒用例覆盖恢复后的持续传输。 |
| 固定 640×360、700 kbit/s | 40 秒 | 三个网络阶段都有媒体传输。固定选择生效后持续保持 360p，未观察到切回自动模式。 |
| 自动画质，响应正文暂停 | 40 秒 | 第 10–15 秒媒体正文写入为 0 字节。恢复后写入 671,599 字节媒体数据，播放推进至 40 秒。公开重缓冲计数全程为 0。 |

限速配置为 500,000 B/s 起播，第 10 秒降至 50,000 B/s，第 25 秒恢复至 500,000 B/s。每轮使用独立的回环服务、运行标识与 USB 端口映射，网络时钟从首个 GET 开始。画质取自约每 250 ms 采集的公开播放器状态。分段请求时刻与输出尺寸变化分别记录，两者会因预缓冲而相差数秒。[受控网络配置](../../../tool/playback_network/profiles.json) · [播放器测试入口](../../../packages/yl_player/example/integration_test/abr_network_profile_test.dart)

源码提交为 `9f02a583`。使用本机 Gradle 9.5 和 Flutter 3.50.0 离线构建 Debug APK，沿用 `skipDependencyChecks` 构建参数。每轮将运行标识和配置编入 APK，安装后核对 SHA-256。采集器按本次应用进程读取 Flutter 测试终态，回执的 `frameworkExitStatus` 由该终态映射而来。限速用例通过仓库汇总器逐轮重放；5 秒正文暂停用例单独核对分阶段字节、恢复后播放进度和框架终态。原始采样、请求和服务收尾回执已归档，逐文件哈希见结果索引。[原始记录](evidence/2026-11-21-android-oppo-abr/captures.tar.xz)

本次结论适用于这台 Android 12 真机与上述网络配置。API 24 真机、重复测量和物理音画输出验收仍开放。5 秒正文中断期间设备已有缓冲，本轮覆盖了网络恢复后持续播放；播放器缓冲耗尽后重新起播仍待单独验证。
